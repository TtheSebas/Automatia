# Automatia — IA Práctica para Negocios Reales

Sitio web comercial multivista de alta conversión para servicios de automatización con Inteligencia Artificial enfocados en PyMEs, talleres, consultorios y empresas de servicios.

## 🚀 Propuesta de Valor

- **Atención por WhatsApp 24/7:** Respuestas inmediatas sobre horarios, cobertura, catálogos y consultas frecuentes.
- **Cotizaciones Automáticas:** De solicitudes por chat a presupuestos formales en PDF desglosados en segundos.
- **Human-in-the-Loop:** Supervisión humana garantizada antes del envío de documentos comerciales.
- **Transparencia Total:** Sin tecnicismos vacíos ni falsas promesas de infalibilidad.

## 🛠️ Stack Tecnológico

- **Framework:** [React 19](https://react.dev/) + [Vite](https://vite.dev/)
- **Enrutamiento:** [React Router v7](https://reactrouter.com/) (Arquitectura multivista tipo micrositio)
- **Estilos:** CSS Modules con paleta cálida a medida (Terracota, Verde Salvia, Arena)
- **Iconografía:** [Lucide React](https://lucide.dev/)
- **Tipografía:** Manrope (Google Fonts)

## 📁 Arquitectura de Vistas

- `/` — **Inicio:** Hero de conversión, WhatsApp Mockup interactivo, beneficios rápidos y "¿Te suena?".
- `/como-funciona` — **Cómo funciona:** Proceso de 4 pasos y arquitectura Human-in-the-Loop.
- `/soluciones` — **Soluciones:** 5 módulos de automatización con ejemplos prácticos.
- `/demo` — **Demostración:** Simulador interactivo del recorrido de 90 segundos.
- `/casos-de-uso` — **Casos de uso:** Manufactura, clínicas, inmobiliarias y criterios de honestidad comercial.
- `/precios` — **Precios:** Tarifas transparentes de implementación y mantenimiento + análisis de ROI.
- `/faq` — **Preguntas frecuentes:** Respuestas claras a las 9 dudas más comunes.
- `/auditoria` — **Auditoría:** Página de conversión principal con formulario adaptado a PyMEs.

## 💻 Instalación y Desarrollo Local

```bash
# 1. Clonar el repositorio
git clone https://github.com/TtheSebas/Automatia.git

# 2. Entrar a la carpeta del proyecto
cd Automatia

# 3. Instalar dependencias
npm install

# 4. Iniciar servidor de desarrollo
npm run dev

# 5. Compilar para producción
npm run build
```
